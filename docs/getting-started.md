# 首次使用

当前为国行普通版小米手环 9，配套手机与手环版本均为 **0.3.3**。高德仍在手机上负责导航。

1. 获取维护者提供的配套已签名 APK、RPK 和 SHA256SUMS.txt。源码检出不包含安装包，本次源码推送未创建 Release。
2. 手机安装 `WristAMap-phone-0.3.3.apk`，AstroBox 选择“快应用”安装 `WristAMap-band9-0.3.3.rpk`。双端包名应为 `io.github.azuresora.wristamap`，签名必须匹配，不混用上游包。
3. 安装后断开 AstroBox，恢复小米运动健康连接。
4. 打开腕上高德，开启通知使用权、附近设备权限、互联授权及同步。手机应用的通知发送权限可关闭；不要关闭高德导航通知或本应用的通知使用权。
5. 保持自动打开与导航常亮开启，在高德开始步行或骑行，核对手环指引。结束导航时手环导航页会退出；最终落到表盘或启动器由固件决定。
6. 手环底部齿轮调整字号、箭头大小和粗细。当前仅使用系统字体，旧自定义字体设置自动回退。

锁屏后台权限、唤醒与耗电策略见 [后台同步](background-sync.md)。不使用时可关闭手机应用内同步开关，停止本应用前台服务并释放唤醒锁。

如果没有反应，依次检查高德通知、通知使用权是否实际连接、同步开关、运动健康连接与双端身份。此前出现过“已有通知使用权但监听未绑定”，重新开启本应用通知使用权后恢复；不保证每个故障都由此引起。不要为排障重置手环或混用签名。

用户已确认当前功能正常；耗电、长期后台与重启恢复仍待测。完整证据见 [适配记录](band9-adaptation.md)。
