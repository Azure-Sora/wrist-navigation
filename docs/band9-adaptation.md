# 手环 9 适配：0.3.0

本分支基于 Gu-Mie/wrist-navigation（MIT），面向国行普通版小米手环 9（192×490）。上游的 9 Pro 历史验证不代表本设备验证通过。

## 当前行为

- 手机读取高德通知，经小米运动健康 / XMS 同步。无需 Root 或 LSPosed。
- 导航开始请求打开手环；前台导航全程常亮。离开页面、进入设置、结束、断连或消息超过20秒未续期时释放。
- 默认96px箭头，单独显示动作距离；原始指引仍可滚动。全程剩余距离不冒充路口距离。
- 方向变化时短振；距非直行动作50米以内短振，同段去重；明确到达目的地时长振。单纯取消导航不振动。
- 通知不提供稳定步骤ID；连续同向动作通过近距离后增加至100米以上重新允许提醒，是启发式判断，不能保证所有连续路口准确区分。当前50米为统一试用阈值，尚未按步行/骑行速度调优。
- 导航指引通知优先于并存的持续导航服务通知，结束状态按时间判断。更新由通知驱动，最小发送间隔500ms，8秒心跳。心跳不表示高德距离已发生更新。

## 独立应用身份

APK/RPK统一包名 `io.github.azuresora.wristamap`，独立生成配套开发签名，密钥仅保留在被忽略的signing/与wearable/sign/目录。源码Java namespace保留原名称。
本版本为debug试用包；不能与上游APK/RPK交叉配对，也不能替代原签名进行覆盖升级。后续升级必须保留本fork的签名。
